# Dynxfault Vanilla+

Enhanced vanilla/default resource pack designed to provide **beautiful, aesthetic, and lightweight visual experience** for both _PvP_ and _Survival_.

---

## Features

- 16x16 textures
- Short clipped sword
- Sharp axe
- Low fire overlay
- Low shield overlay
- Small totem
- Fast/opaque leaves
- Minimal particle textures (**Bedrock-only**)
- **Supports Java and Bedrock**

---

## Requirements

1. **Minecraft: Java Edition** (26.3+)
2. **Minecraft: Bedrock Edition** (26.51+)
3. [**Blurry's Crossplay Animations**](https://www.curseforge.com/minecraft-bedrock/addons/blurrys-crossplay-animations) (optional, **Bedrock-only**)
